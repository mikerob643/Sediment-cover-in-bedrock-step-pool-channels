# Data tables for “Sediment cover in bedrock step-pool channels counter-intuitively increases with increasing water discharge”

Albarran Ayala, A. J., Robinson, M. J., Takase, M., Inoue, T., & Scheingross, J. S., Journal of Geophysical Research: Earth Surface, manuscript 2025JF008956R (in revision).
